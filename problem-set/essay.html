Course · 서술형 답안 연습

    외우지 말고,
    구조로 서술하기

    이 과목 기말은 대부분 서술형이다. 서술형은 "정의를 아느냐"가 아니라 "왜 그 구조이고, 언제 쓰며, 무엇과 어떻게 다른가를 논리적으로 풀어낼 수 있느냐"를 본다. 아래 예상 문제를 먼저 직접 써 본 뒤, 답안 골격을 펼쳐 빠진 축을 점검하라.

    ✍️ 서술형 답안 골격 — 이 순서로 쓰면 빠뜨리지 않는다

    1. 정의 — 패턴의 의도를 한 문장으로. ("…를 캡슐화하여 …하게 한다")
    2. 동기(왜) — 이 패턴이 없을 때 생기는 문제(분기 폭발, 강결합, 클래스 폭발 등). 채점의 핵심.
    3. 구조 — 핵심 참여자와 관계. 합성/위임이 어디에 들어가는지.
    4. 결과 — 장점(어떤 변경에 강해지는가)과 단점(트레이드오프).
    5. 적용 예시 — 구체적 상황 하나. 추상 설명 뒤 반드시 예시.
    6. 원칙 연결 — OCP, DIP, "상속보다 합성" 중 어떤 것을 실현하는지 한 줄.

    비교형 문제는 골격이 다르다: 공통점(구조/목적) → 의도의 결정적 차이 → 각각의 적용 상황 → 한 줄 요약. "구조가 같아 보이지만 의도가 다르다"를 명시하는 것이 고득점 포인트다.

    아래 12문항은 정의형(define-and-explain), 비교형(compare), 적용형(when-to-use), 원칙형(principle)으로 골고루 구성했다. 각 문항을 먼저 백지에 직접 서술하고 나서 "답안 골격 보기"를 펼쳐라. 골격은 모범답안 전문이 아니라 반드시 들어가야 할 논점의 뼈대다. 자신의 답에 빠진 축이 있으면 그 패턴의 본문으로 돌아가 보강하라.
