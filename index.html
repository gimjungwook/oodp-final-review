GoF 12개 디자인 패턴을 의도 → 구조(UML) → 코드 → 자주 헷갈리는 함정 순서로 풀고, 시스템·객체 설계와 패턴 선택 의사결정까지 한 사이트로 정리했다. 각 패턴마다 클래스 다이어그램과 인터랙티브 위젯으로 "왜 그 구조인가"를 직접 확인한다.

챕터 6 핵심 패턴 12 Problem Set 백지 테스트

패턴은 외우는 게 아니라 "어떤 변화를 캡슐화하려는가"로 떠올린다. 각 챕터는 그 변화의 축이 무엇인지부터 시작한다.

한빛 「Java 객체지향 디자인 패턴」, GoF 「Design Patterns」, Bruegge & Dutoit 「Object-Oriented Software Engineering」 기반 기말 복습 자료.
