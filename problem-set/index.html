왜 백지 테스트인가

보면서 "아 이해했다"고 느끼는 것과, 시험지 위 백지에서 구조를 직접 꺼내 그리는 것은 전혀 다른 능력이다. 전자는 재인(recognition)이고 후자는 인출(retrieval)이다. 시험장에서 필요한 건 후자다. 이 코스는 정답을 <details> 접기 뒤에 숨겨 두었다. 먼저 백지에 직접 쓴 다음, "정답 보기"를 눌러 채점하라. 이 순서를 지켜야 인출 연습(retrieval practice)의 효과가 살아난다.

채점 기준은 맞고 틀림이 아니라 "왜 그 답인가"를 말로 설명할 수 있는지다. 패턴 이름을 떠올리는 데서 그치지 말고, 그 패턴이어야 하는 근거 — 어떤 변화 축을 흡수하는지, 어떤 결합을 끊는지 — 까지 함께 떠올려라. 막히면 각 챕터의 sub-chapter 본문으로 돌아가라.

🧠 푸는 순서

  1. A → B → C → D 순으로, 한 코스를 다 풀 때까지 정답을 펼치지 않는다.
  2. 각 문항을 백지(혹은 종이)에 직접 손으로 써 본 뒤에만 "정답 보기"를 펼친다.
  3. 틀린 문항만 표시해 두고 다음 날 다시 푼다 — 같은 과목을 몰아 풀지 말고 사이에 간격을 둔다.
